# ADR-0019｜前台 SEO 與正式部署模式策略

- 狀態：已採納
- 日期：2026-06-02
- 關聯文件：`05_前台與後台Vue正式部署流程.md`、`08_完整系統開發部署流程清單.md`

## 1. 背景與問題

前台電商頁面需要讓顧客瀏覽商品，也可能需要搜尋引擎收錄。純 SPA 雖然開發快速，但 SEO、社群分享預覽與首屏效能可能需要額外處理。

## 2. 決策

初期 Storefront 可先採 Vue SPA 部署，但需保留未來導入 SSR、SSG 或預渲染的彈性。Admin App 不追求 SEO，並應避免被搜尋引擎索引。

## 3. 理由

- 初期 SPA 可降低開發複雜度。
- 正式電商未來可能需要 SEO 強化。
- 後台不應被搜尋引擎收錄。

## 4. 實作要求

```text
□ Storefront 頁面需設定 title、description、canonical 等基本 SEO
□ 商品詳細頁需規劃可分享的 URL
□ Admin App 設定 noindex 或由伺服器阻擋索引
□ 靜態資源需使用快取策略
□ 前端 Build 不包含 .env 機密
□ API Base URL 透過環境設定管理
□ 若 SEO 成為重要需求，再評估 SSR / SSG / 預渲染
```

## 5. 驗收檢查

```text
□ 前台商品 URL 可直接開啟
□ 後台頁面不被搜尋引擎索引
□ 前端沒有打包後端機密
□ 靜態資源可快取但不影響新版部署
```
