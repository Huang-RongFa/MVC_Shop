# ADR 決策總覽｜正式部署校正版

本資料夾為電商網站正式部署版 ADR（Architecture Decision Record）。

## 使用規則

```text
□ 修改架構前先查 ADR
□ 若文件與 ADR 衝突，先修正 ADR 或新增 ADR
□ 若程式碼與 ADR 衝突，優先回到 ADR 檢查是否需要改決策
□ 正式部署前，必須檢查 0012～0020 的上線、安全、監控與備份決策
```
