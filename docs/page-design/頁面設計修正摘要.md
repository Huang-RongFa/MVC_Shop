# 頁面設計修正摘要

## 1. 本次新增目的

本次依照目前 `Views` 資料夾與 DayNight Admin HTML / CSS / JS 版型，補上一套可放入 `docs/page-design/` 的頁面設計規劃文件。

重點是讓專案清楚知道：

```text
□ 哪些頁面屬於前台
□ 哪些頁面屬於後台
□ 哪些頁面屬於登入與帳號流程
□ HTML 版型如何轉成 cshtml
□ CSS / JS 應放在哪裡
□ 前台未登入能看什麼
□ 登入後才能買什麼
□ 後台管理員才能看哪些數據
□ AGENTS / CONTEXT / README 要如何理解頁面需求
```

---

## 2. 核心決策

```text
前台頁面不顯示數據分析。
後台管理員登入後才顯示 Dashboard、Analytics 與營運管理資料。
尚未登入的使用者可以瀏覽商品樣式與商品詳細。
登入後才可以加入購物車、結帳與查詢訂單。
DayNight Admin 版型作為視覺來源，不作為正式商業邏輯來源。
```
