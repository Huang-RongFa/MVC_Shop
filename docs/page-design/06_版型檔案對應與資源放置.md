# 06｜版型檔案對應與資源放置

## 1. 原始檔案與用途對應

| 原始檔案 | 建議用途 | 轉換後位置 |
|---|---|---|
| `templatemo-daynight-style.css` | 共用視覺樣式 | `wwwroot/css/daynight.css` |
| `templatemo-daynight-script.js` | 主題切換、手機選單、互動效果 | `wwwroot/js/daynight.js` |
| `login.html` | 登入樣式 | `Views/Account/Login.cshtml`、`Views/Admin/Login.cshtml` |
| `index.html` | 後台 Dashboard | `Views/Admin/Index.cshtml` |
| `analytics.html` | 後台數據分析 | `Views/Admin/Analytics.cshtml` |
| `projects.html` | 看板式管理 | `Views/Admin/Products.cshtml` 或 `Views/Admin/Orders.cshtml` |
| `inbox.html` | 訊息 / 通知 | `Views/Admin/Inbox.cshtml` |
| `settings.html` | 後台設定與會員資料表單 | `Views/Admin/Settings.cshtml`、`Views/Account/Profile.cshtml` |
| `about-templatemo.html` | 前台品牌介紹、商品展示區塊 | `Views/Home/About.cshtml`、`Views/Home/Index.cshtml` |

---

## 2. wwwroot 建議結構

```text
wwwroot/
├─ css/
│  ├─ daynight.css
│  ├─ storefront.css
│  └─ admin.css
│
├─ js/
│  ├─ daynight.js
│  ├─ storefront.js
│  └─ admin.js
│
├─ images/
│  ├─ products/
│  ├─ banners/
│  └─ uploads/
│
└─ lib/
   └─ bootstrap/
```

---

## 3. CSS 拆分建議

先期可以直接使用：

```text
wwwroot/css/daynight.css
```

後續穩定後再拆：

```text
daynight.css      原版型共用樣式
storefront.css    前台商品、購物車、結帳補充樣式
admin.css         後台管理頁補充樣式
```

不要把大量 CSS 寫在 `.cshtml` 內，除非是非常小的單頁調整。

---

## 4. JavaScript 拆分建議

先期：

```text
wwwroot/js/daynight.js
```

後續：

```text
daynight.js       主題切換、手機選單、共用互動
storefront.js     加入購物車、商品篩選、結帳互動
admin.js          後台表格、看板、日期篩選、二次確認
```

---

## 5. Layout 引用範例

```html
<link rel="stylesheet" href="~/css/daynight.css" asp-append-version="true" />
<script src="~/js/daynight.js" asp-append-version="true"></script>
```

正式環境建議加上 `asp-append-version="true"`，讓檔案更新後瀏覽器能拿到新版本。

---

## 6. Bootstrap CDN 處理

版型使用 Bootstrap CDN。正式上線時有兩種選擇：

| 做法 | 適合情境 |
|---|---|
| 繼續用 CDN | 快速部署，但需注意 CDN 可用性與安全 |
| 放入 `wwwroot/lib` | 控制版本、降低外部依賴，更適合正式系統 |

正式環境若使用 CDN，應評估：

```text
□ 固定版本
□ 使用 HTTPS
□ 使用 SRI integrity
□ 設定 crossorigin
```

---

## 7. 本章總結

HTML 版型應拆成 Razor Views，CSS / JS 則集中放入 `wwwroot`。不要讓每個頁面各自複製一份導覽列、主題切換、手機選單與 Script，否則後續維護會很困難。
