# 03｜前台頁面設計清單

## 1. 前台設計目標

前台頁面要讓使用者在尚未登入時，也能先看到產品樣式、商品分類、商品特色與品牌資訊。登入後才可以加入購物車、結帳、付款與查詢自己的訂單。

前台不顯示後台營收、使用者成長、轉換率、訂單總數等營運分析資訊。

---

## 3. 前台首頁設計

首頁應包含：

```text
□ 品牌 Logo / 導覽列
□ Hero 區塊：水果、蔬菜、新鮮、快速配送等主訴求
□ 商品分類：水果、蔬菜、冷藏、促銷商品
□ 精選商品卡片：圖片、名稱、價格、簡介
□ 促銷活動區塊
□ 加入購物車按鈕
□ 頁尾資訊：關於我們、客服、隱私權、聯絡方式
```

未登入狀態：

```text
□ 可瀏覽商品
□ 可查看商品詳細
□ 點擊加入購物車時導向登入或提示需登入
```

登入狀態：

```text
□ 可加入購物車
□ 可查看購物車
□ 可進入結帳
□ 可查看我的訂單
```

## 4. 商品卡片基本欄位

```text
商品圖片
商品名稱
商品簡介
售價
促銷標籤
庫存狀態
商品分類
查看詳細按鈕
加入購物車按鈕
```

注意：

```text
□ 價格由後端提供，不相信前端自行計算
□ 庫存狀態由後端提供，不直接暴露內部精確庫存也可以
□ 優惠價格由後端計算
□ 商品圖片需有 alt 文字
```

## 6. 本章總結

前台重點是「商品展示 → 登入 → 加入購物車 → 結帳 → 訂單查詢」。即使使用 DayNight 卡片與表單樣式，也要把內容改成電商顧客使用情境，而不是後台管理情境。
