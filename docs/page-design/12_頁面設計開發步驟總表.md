# 12｜頁面設計開發步驟總表

## 1. 第一階段：整理靜態資源

```text
□ 複製 templatemo-daynight-style.css 到 wwwroot/css/daynight.css
□ 複製 templatemo-daynight-script.js 到 wwwroot/js/daynight.js
□ 確認 Bootstrap 引用方式
□ 建立 images/products、images/banners 資料夾
□ 確認主題切換正常
```

---

## 2. 第二階段：建立 Layout

```text
□ 建立 _StorefrontLayout.cshtml
□ 建立 _AdminLayout.cshtml
□ 建立 _AuthLayout.cshtml
□ 建立 _StorefrontHeader.cshtml
□ 建立 _AdminHeader.cshtml
□ 建立 _MobileMenu.cshtml
□ 建立 _ThemeToggle.cshtml
```

---

## 3. 第三階段：建立前台公開頁

```text
□ Home/Index.cshtml
□ Home/About.cshtml
□ Products/Index.cshtml
□ Products/Details.cshtml
□ Account/Login.cshtml
□ Account/Register.cshtml
□ Account/ForgotPassword.cshtml
```

驗收：

```text
□ 未登入可看首頁
□ 未登入可看商品列表
□ 未登入可看商品詳細
□ 未登入點購買會提示登入
□ 前台不顯示後台 Dashboard / Analytics
```

---

## 4. 第四階段：建立前台會員頁

```text
□ Cart/Index.cshtml
□ Checkout/Index.cshtml
□ Checkout/Complete.cshtml
□ Orders/Index.cshtml
□ Orders/Details.cshtml
□ Account/Profile.cshtml
```

驗收：

```text
□ 未登入不能進購物車
□ 未登入不能結帳
□ 會員只能看自己的訂單
□ 商品價格由後端提供
□ 建立訂單後保留庫存
```

---

## 5. 第五階段：建立後台登入與 Dashboard

```text
□ Admin/Login.cshtml
□ Admin/Index.cshtml
□ Admin/Analytics.cshtml
```

驗收：

```text
□ Customer 不能進後台
□ Admin / Staff 才能進後台
□ Dashboard 數據來自 ViewModel
□ Analytics 只在後台顯示
```

## 7. 第七階段：替換假資料

```text
□ 建立 ViewModel
□ Controller 呼叫 Service
□ Service 組合資料
□ View 使用 Model 顯示
□ 移除 Alex / Sarah 等模板假資料
□ 移除假營收、假訂單、假訪客數
```

---

## 8. 第八階段：資安與正式上線檢查

```text
□ 表單加入 CSRF
□ 後台加 Authorize
□ 後台操作檢查 Permission
□ 錯誤訊息不顯示 Stack Trace
□ 不使用未清理 innerHTML
□ CSS / JS 加版本
□ RWD 測試
□ 瀏覽器測試
□ 上線前 Smoke Test
```

---

## 9. 本章總結

頁面設計應先完成共用 Layout，再做前台公開頁、前台會員頁、後台 Dashboard、後台管理頁，最後替換假資料並加入正式上線檢查。
