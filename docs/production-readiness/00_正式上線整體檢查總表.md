# 00｜正式上線整體檢查總表

> 版本：2026-06-02  
> 文件目的：作為正式部署前後的總驗收表，避免只完成開發卻缺少營運安全能力。

---

## 1. 上線前總目標

正式上線不是只把網站部署到伺服器，而是要確認下列事項都可被驗證：

```text
□ 使用者可以穩定進入網站
□ API 可安全處理請求
□ 資料庫資料一致且可備份還原
□ 金流與物流流程不會混用測試環境
□ 錯誤可以被記錄與告警
□ 發生部署失敗時可以回滾
□ 發生資料或服務事故時有復原方案
□ 網站被惡意請求攻擊時不會因為沒有基本保護而立即崩潰
```

---

## 2. 正式上線成熟度判斷

| 類別 | 已有基礎 | 正式上線必補 |
|---|---|---|
| 資料庫 | MSSQL、ERD、索引、交易流程 | 備份還原演練、RPO / RTO、資料保存週期、正式資料不可手動任意修改 |
| 後端 | Controller / Service / Repository | Rate Limiting、Health Check、ProblemDetails、API 版本、回滾、套件弱點掃描 |
| 前端 | Storefront / Admin Vue | Production Build、環境變數、Source Map 控制、錯誤追蹤、SEO、瀏覽器測試 |
| 資安 | OWASP 基本檢查 | CSRF、CORS 白名單、Security Headers、Secret Rotation、WAF、登入防暴力破解 |
| 部署 | 基本部署清單 | CI/CD、Staging 驗收、Artifact 保存、可回滾部署、資料庫變更流程 |
| 營運 | 稽核資料表 | 監控、告警、集中 Log、Trace Id、事故處理流程 |
| 金流物流 | 資料表與 API 規劃 | 正式 / 測試隔離、Webhook 驗簽、冪等、退款權限、敏感資料不落地 |

---

## 3. 不可上線條件

只要符合任一條，就不建議正式啟用：

```text
□ Production 連線字串或金鑰寫在 Git 內
□ 正式環境仍使用測試金流或測試物流金鑰
□ Cookie 驗證已啟用，但寫入型 API 沒有 CSRF 防護規劃
□ CORS 使用 AllowAnyOrigin 且允許 Cookie / Credentials
□ Swagger 正式環境匿名公開完整後台 API
□ 登入 API 沒有 Rate Limiting 或失敗紀錄
□ 資料庫沒有備份，或備份從未測試還原
□ 金流 Callback 沒有驗簽或無法防止重複處理
□ 錯誤會把 Stack Trace、SQL、檔案路徑顯示給使用者
□ 沒有回滾方案，部署失敗只能手動猜測修復
```

## 4. 上線前必備清單

### 網路與網域

```text
□ 網域已設定
□ DNS 已指向正式環境
□ www、admin、api 網域分工清楚
□ HTTPS 憑證有效
□ HTTP 自動導向 HTTPS
□ HSTS 已在 Staging 驗證
□ MSSQL 不直接暴露到網際網路
□ SSH / RDP 僅允許必要來源
```

### 後端與 API

```text
□ Production appsettings 不上傳 Git
□ Cookie / Token 簽章金鑰使用正式機密
□ 前台 API 與後台 API 路由邊界已確認
□ CORS 只允許正式前端網域
□ CSRF 防護已套用於寫入型 API
□ Rate Limiting 已套用高風險 API
□ Swagger 正式環境關閉或加權限
□ 全域錯誤處理不外洩內部資訊
□ Health Check 可檢查 API 與 DB
```

### 前端

```text
□ Storefront App 與 Admin App 分開建置或分開部署
□ Storefront API Base URL 使用正式 API
□ Admin API Base URL 使用正式 API
□ Source Map 是否公開已評估
□ 不輸出敏感 console.log
□ Admin 頁面不被搜尋引擎索引
```

### 資料與第三方服務

```text
□ 資料庫連線字串使用正式機密管理
□ 資料庫備份已啟用
□ 備份還原已測試
□ 金流正式環境金鑰已確認
□ 物流正式環境金鑰已確認
□ 測試資料不在正式資料庫
□ 金流 Callback 驗簽與冪等已完成
```

### 營運與事故處理

```text
□ Log 可查詢
□ 重要錯誤有告警
□ 部署失敗可回滾
□ 事故負責人與聯絡方式已確認
□ 上線後觀察期間已安排
```

## 5. 上線後必備檢查

```text
□ 首頁可正常開啟
□ 登入流程正常
□ 商品列表正常
□ 加入購物車正常
□ 建立訂單正常
□ 付款流程正常
□ 付款 Callback 正常
□ 出貨流程正常
□ 後台訂單查詢正常
□ Log 沒有大量錯誤
□ API 5xx 錯誤率正常
□ CPU / Memory / DB 連線數正常
□ 備份任務正常
□ 沒有異常登入或大量 401 / 403
□ 沒有付款狀態卡住或重複付款事件
```

---

## 6. 本章總結

正式上線要同時看功能、資安、效能、資料保護與營運能力。網站能開不代表能正式營運；只要部署、備份、監控、金流或資安其中一項無法驗證，都應先補齊再正式啟用。
