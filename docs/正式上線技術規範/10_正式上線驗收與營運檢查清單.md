# 10｜正式上線驗收與營運檢查清單

## 1. 上線前一天

```text
□ 確認本次版本號
□ 確認部署內容
□ 確認資料庫備份
□ 確認回滾方案
□ 確認金流正式環境
□ 確認物流正式環境
□ 確認 DNS 與 TLS
□ 確認監控與告警
□ 確認負責人與聯絡方式
```

---

## 2. 上線當下

```text
□ 部署後端
□ 部署前端
□ 執行資料庫變更
□ 執行 Smoke Test
□ 檢查 API 健康狀態
□ 檢查前台首頁
□ 檢查後台登入
□ 檢查商品查詢
□ 檢查訂單建立
□ 檢查付款流程
```

---

## 3. 上線後一小時

```text
□ API 錯誤率正常
□ API 回應時間正常
□ 資料庫 CPU / Memory 正常
□ DB 連線數正常
□ Log 無大量錯誤
□ 金流 Callback 正常
□ 訂單數量合理
□ 後台可正常操作
```

---

## 4. 上線後一天

```text
□ 備份任務成功
□ 沒有異常登入
□ 沒有大量 4xx / 5xx
□ 沒有付款狀態卡住
□ 沒有庫存異常
□ 稽核紀錄正常
□ 客服或營運回報已確認
```

---

## 5. 事故處理基本流程

```text
1. 確認問題現象
2. 判斷影響範圍
3. 決定修復或回滾
4. 保留 Log 與資料
5. 修復後重新驗證
6. 記錄事故原因
7. 補上預防措施
```

---

## 6. 本章總結

上線不是部署完成就結束，而是要完成上線前、上線中、上線後的驗收。正式營運系統需要能觀察、能回滾、能追蹤、能復原。
