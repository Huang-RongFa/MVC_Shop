# 00｜正式上線整體檢查總表

## 1. 上線前總目標

正式上線不是只把網站部署到伺服器，而是要確認下列事項都可被驗證：

```text
□ 使用者可以穩定進入網站
□ API 可安全處理請求
□ 資料庫資料一致且可備份還原
□ 金流與物流流程不會混用測試環境
□ 錯誤可以被記錄與告警
□ 發生部署失敗時可以回滾
□ 發生資料或服務事故時有復原方案
```

---

## 2. 上線成熟度判斷

| 類別 | 目前 MSSQL / MVC 文件 | 正式上線仍需確認 |
|---|---|---|
| 資料庫 | 已有完整資料表、ERD、索引與部署檢查 | 備份演練、RPO / RTO、資料保存週期 |
| 後端 | 已有 Controller / Service / Repository 規劃 | Rate Limit、Health Check、API 版本、回滾 |
| 前端 | 已有 Vue 流程 | Storefront / Admin 分離、Build、環境變數、瀏覽器相容、錯誤追蹤 |
| 資安 | 已有 OWASP 基本檢查 | HSTS、Security Headers、Secret Rotation |
| 部署 | 有基本部署清單 | CI/CD、Blue-Green 或可回滾部署 |
| 營運 | 有稽核資料表 | 監控、告警、集中 Log、事件處理流程 |
| 金流物流 | 有資料表與 API 規劃 | 正式 / 測試環境隔離、Webhook 驗簽、PCI 範圍 |

---

## 3. 上線前必備清單

```text
□ 網域已設定
□ DNS 已指向正式環境
□ HTTPS 憑證有效
□ HSTS 規劃完成
□ Production appsettings 不上傳 Git
□ Cookie / Token 簽章金鑰使用正式機密
□ Storefront App 與 Admin App 已分開部署或分開建置
□ 前台 API 與後台 API 路由邊界已確認
□ 資料庫連線字串使用正式機密管理
□ CORS 只允許正式前端網域
□ Swagger 正式環境關閉或加權限
□ 錯誤訊息不顯示 Stack Trace
□ Log 可查詢
□ 重要錯誤有告警
□ 資料庫備份已啟用
□ 備份還原已測試
□ 金流正式環境金鑰已確認
□ 物流正式環境金鑰已確認
□ 測試資料不在正式資料庫
□ 部署失敗可回滾
```

---

## 4. 上線後必備檢查

```text
□ 首頁可正常開啟
□ 登入流程正常
□ 商品列表正常
□ 加入購物車正常
□ 建立訂單正常
□ 付款流程正常
□ 付款 Callback 正常
□ 出貨流程正常
□ 後台訂單查詢正常
□ Log 沒有大量錯誤
□ CPU / Memory / DB 連線數正常
□ 備份任務正常
```

---

## 5. 本章總結

正式上線要同時看功能、資安、效能、資料保護與營運能力。只要其中一項沒有檢查，網站雖然能開，但不代表已經符合正式營運需求。
