# 13｜頁面設計驗收清單

## 1. 前台驗收

```text
□ 未登入可進首頁
□ 未登入可看商品列表
□ 未登入可看商品詳細
□ 未登入點購買會提示登入或導向登入
□ 登入後可加入購物車
□ 登入後可查看購物車
□ 登入後可結帳
□ 登入後可查看自己的訂單
□ 前台不顯示 Dashboard
□ 前台不顯示數據分析
□ 前台不顯示後台管理選單
```

---

## 2. 後台驗收

```text
□ 後台頁面必須登入
□ Customer 不能進後台
□ Admin / Staff 才能進後台
□ Dashboard 顯示電商營運資料
□ Analytics 只在後台顯示
□ 商品管理需 Products.Read / Products.Write
□ 庫存調整需 Inventory.Adjust
□ 退款管理需 Refunds.Manage
□ 稽核紀錄需 AuditLogs.Read
□ 沒權限時不顯示選單
□ 直接輸入 URL 時後端仍會擋權限
```

---

## 3. 版型驗收

```text
□ CSS 正常載入
□ JS 正常載入
□ Snow / Carbon 主題可切換
□ 手機選單可開關
□ 桌機版導覽列正常
□ 表單樣式一致
□ 卡片樣式一致
□ 表格樣式一致
□ RWD 正常
```

---

## 4. 資料驗收

```text
□ View 不直接使用 Entity
□ 頁面使用 ViewModel
□ Controller 不直接查 DbContext
□ 假資料已逐步移除
□ 商品價格由後端提供
□ 優惠折扣由後端計算
□ 庫存狀態由後端提供
□ Dashboard 數據由 Service 組合
```

---

## 5. 資安驗收

```text
□ 所有 POST 表單有 Anti-forgery Token
□ 後台 Controller 有 Authorize
□ 高風險操作檢查 Permission
□ 不把 PasswordHash 顯示到 View
□ 不把 Token / Cookie 寫入頁面
□ 不在 localStorage 存高權限 Token
□ 不使用未清理 Html.Raw
□ 不把使用者輸入直接放入 innerHTML
□ 正式環境不公開詳細錯誤
```

---

## 6. 正式上線前驗收

```text
□ Production Build / Publish 正常
□ 靜態資源有版本控制
□ Source Map 是否公開已評估
□ Bootstrap / 第三方資源版本固定
□ 圖片最佳化
□ SEO Meta 基本設定
□ Admin 頁面 noindex
□ 404 / 500 頁面正常
□ 登入逾時導向正確
□ 權限不足頁面正常
```

---

## 7. 本章總結

頁面完成不只是看起來像版型，而是要符合前後台邊界、登入權限、資料來源、RWD、資安與正式上線要求。
