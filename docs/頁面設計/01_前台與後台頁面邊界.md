# 01｜前台與後台頁面邊界

## 1. 頁面邊界總原則

本專案頁面分成三大區域：

```text
前台 Storefront：顧客使用
後台 Admin：管理員與員工使用
帳號 Auth：登入、註冊、忘記密碼
```

前台頁面可以公開瀏覽商品，但不顯示後台營運數據。後台頁面必須登入並通過 Role / Permission 檢查。

---

## 2. 前台頁面定位

前台目標是讓顧客完成購物流程。

前台允許未登入看到：

```text
□ 首頁
□ 商品列表
□ 商品詳細
□ 商品分類
□ 關於我們
□ 登入頁
□ 註冊頁
□ 忘記密碼頁
```

前台必須登入才能使用：

```text
□ 加入購物車
□ 查看購物車
□ 結帳
□ 建立訂單
□ 付款
□ 我的訂單
□ 訂單詳細
□ 會員資料
```

前台禁止顯示：

```text
□ 總營收
□ 活躍使用者
□ 轉換率
□ 後台數據分析
□ 訂單總覽管理
□ 付款管理列表
□ 庫存調整
□ 退款管理
□ 稽核紀錄
```

---

## 3. 後台頁面定位

後台目標是管理電商營運資料。

後台必須登入且具備權限才能看到：

```text
□ Dashboard
□ 數據分析
□ 使用者管理
□ 角色權限管理
□ 商品管理
□ SKU 管理
□ 商品圖片管理
□ 庫存查詢
□ 庫存調整
□ 訂單管理
□ 付款管理
□ 出貨管理
□ 退款管理
□ 優惠券管理
□ 促銷管理
□ 系統訊息 / 客服訊息
□ 稽核紀錄
□ 系統設定
```

---

## 4. 頁面與權限對應

| 頁面 | 使用者 | 是否需登入 | 權限 |
|---|---|---:|---|
| 首頁 | 匿名 / 會員 | 否 | 無 |
| 商品列表 | 匿名 / 會員 | 否 | 無 |
| 商品詳細 | 匿名 / 會員 | 否 | 無 |
| 加入購物車 | 會員 | 是 | Customer |
| 結帳 | 會員 | 是 | Customer |
| 我的訂單 | 會員 | 是 | Customer 且本人資料 |
| Admin Dashboard | Admin / Staff | 是 | Dashboard.Read |
| Admin 商品管理 | Admin / Staff | 是 | Products.Read / Products.Write |
| Admin 庫存調整 | Admin / Staff | 是 | Inventory.Adjust |
| Admin 訂單管理 | Admin / Staff | 是 | Orders.Read / Orders.Write |
| Admin 退款管理 | Admin / Staff | 是 | Refunds.Manage |
| Admin 稽核紀錄 | Admin | 是 | AuditLogs.Read |

---

## 5. Layout 邊界

建議至少拆成三個 Layout：

```text
Views/Shared/_StorefrontLayout.cshtml
Views/Shared/_AdminLayout.cshtml
Views/Shared/_AuthLayout.cshtml
```

| Layout | 用途 |
|---|---|
| `_StorefrontLayout` | 前台首頁、商品、購物車、結帳、會員訂單 |
| `_AdminLayout` | 後台 Dashboard、管理頁、分析頁、設定頁 |
| `_AuthLayout` | 登入、註冊、忘記密碼 |

---

## 6. 本章總結

前台與後台的畫面可以共用 CSS 設計語言，但不能共用頁面邏輯與權限邊界。前台不放數據分析；後台所有管理頁都必須登入與授權。
