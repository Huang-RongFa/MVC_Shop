## 資安檢查

```text
□ POST 表單有 CSRF
□ 後台頁面有 Authorize
□ 高風險操作有 Permission
□ 不直接使用 Entity
□ 不顯示敏感欄位
□ 不使用未清理 Html.Raw
□ 不使用未清理 innerHTML
```
